# Core Contracts (18)

Mọi output quan trọng phải khớp một schema dưới đây. Chỉ thêm schema mới khi có ranh giới thực sự mới.

| Contract | Mô tả |
|---|---|
| `market_data_contract` | Bản ghi dữ liệu thị trường có kiểm soát point-in-time |
| `evidence_item` | Một mảnh bằng chứng trong Evidence Graph |
| `hypothesis` | Ý tưởng đầu tư dạng giả thuyết kiểm chứng được |
| `research_report` | Báo cáo nghiên cứu của một chuyên gia |
| `valuation_case` | Trường hợp định giá |
| `backtest_run` | Một lần chạy backtest |
| `model_card` | Thẻ mô hình |
| `market_regime` | Phân loại regime thị trường |
| `investment_decision` | Gói quyết định đầu tư gửi Owner |
| `risk_assessment` | Đánh giá của Risk Officer — có quyền chặn |
| `portfolio_snapshot` | Ảnh chụp danh mục |
| `trade_record` | Bản ghi giao dịch |
| `attribution_report` | Phân rã kết quả — Learning chỉ học sau báo cáo này |
| `learning_lesson` | Bài học rút ra |
| `knowledge_item` | Mục tri thức (candidate hoặc canonical) |
| `media_story` | Câu chuyện truyền thông |
| `editorial_review` | Duyệt biên tập |
| `conflict_disclosure` | Kiểm tra xung đột lợi ích Đầu tư ↔ Truyền thông |
