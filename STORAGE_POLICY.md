# Chính sách lưu trữ

| Nơi | Chứa |
|---|---|
| **GitHub (repo này)** | kiến trúc, quản trị, contracts, code, tri thức canonical, state |
| **Database** | giá, fundamentals, sự kiện, thí nghiệm, quyết định, danh mục, analytics |
| **Object storage** | báo cáo, hồ sơ, audio/video/ảnh, model artifacts, dataset lớn |
| **Vector / search index** | truy xuất nghiên cứu |
| **Secrets manager** | API key, thông tin broker |
| **Model registry** | mô hình, phiên bản, metric, trạng thái deploy |

**Không bao giờ commit secret, API key, thông tin broker vào GitHub.**
