# Financial Media OS

```text
MARKET DATA / NEWS → NEWSROOM INGESTION → FACT CHECK → FINANCIAL ANALYSIS → EDITOR-IN-CHIEF
→ SCRIPT / CHARTS → VISUAL STORY → YOUTUBE / TIKTOK / SHORTS → AUDIENCE ANALYTICS → MEDIA LEARNING
```

## Workflow chi tiết
```text
MARKET EVENT → SOURCE VERIFICATION → FACT EXTRACTION → FINANCIAL CONTEXT → BULL / BEAR / ALTERNATIVE VIEW
→ EDITORIAL ANGLE → FACT CHECK → CONFLICT CHECK → LEGAL CHECK → SCRIPT → CHARTS → DIRECTING → EDIT → QUALITY GATE
→ PUBLISH (thủ công, auto_publish_enabled=false) → AUDIENCE DATA → MEDIA LEARNING ↺
```

## LEGAL CHECK — bắt buộc, theo `governance/MEDIA_LEGAL_POLICY.md`
- Không khuyến nghị mua/bán/nắm giữ mã cụ thể, kể cả ngầm ("rẻ", "đáng mua", "cơ hội", "vùng giá hấp dẫn", mục tiêu giá, điểm vào/ra).
- Không phân tích từng mã kèm định giá; không kéo người xem vào nhóm kín / khóa học / tư vấn trả phí; không nhắc mã đang trong danh mục giấy/thật.
- Mỗi nội dung có tuyên bố miễn trừ và công bố dùng AI (nếu có giọng/người dẫn AI).
- FAIL ở bất kỳ điểm nào → REJECT, không phải REVISE cho "mềm" đi. Nghi ngờ → dừng ở cổng Owner.

## Media Learning
Học hai thứ tách biệt:
- **Editorial truth:** accuracy, clarity, context, balance, uncertainty.
- **Audience response:** CTR, retention, watch time, comments, returning viewers, shares, subscriber conversion.

Không học `CLICKBAIT WORKED → CLICKBAIT IS GOOD`.
Học `PACKAGING IMPROVED APPEAL AND CONTENT DELIVERED SATISFACTION`.
