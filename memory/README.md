# Hệ thống bộ nhớ

| Loại | Thư mục | Chứa |
|---|---|---|
| Fact | `memory/fact/` | Dữ kiện đã kiểm chứng |
| Reasoning | `memory/reasoning/` | Chuỗi lập luận dẫn tới kết luận |
| Learning | `memory/learning/` | Bài học (LEARNING_LESSON) |
| Economic | `memory/economic/` | Chi phí, lợi nhuận, hiệu quả vốn |
| Procedural | `memory/procedural/` | Quy trình, phương pháp nghiên cứu |
| Episodic | `memory/episodic/` | Quyết định + bối cảnh + regime + kết quả |

Episodic đặt tên `YYYY-MM-DD_<chủ-đề>.md`.
