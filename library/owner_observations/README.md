# NHẬT KÝ QUAN SÁT THỰC ĐỊA CỦA OWNER

Mỗi quan sát tạo một file `YYYY-MM-DD_<chu-de>.md` theo mẫu dưới. Quan sát có liên quan tới mã niêm yết sẽ được chuyển thành dự báo `owner_field@v1` trong Ledger và được chấm điểm.

```text
NGÀY:
NƠI QUAN SÁT:                (ví dụ: 3 cửa hàng X ở quận Y)
SỐ ĐIỂM QUAN SÁT:            (càng nhiều càng đáng tin)
ĐIỀU THẤY:                   (mô tả sự việc, không kết luận)
DOANH NGHIỆP LIÊN QUAN:      (mã, nếu có)
OWNER NGHĨ NÓ DẪN TỚI:       (ví dụ: doanh thu quý tới giảm)
MỨC TIN (%):                 (ví dụ: 60%)
THỜI HẠN KIỂM CHỨNG:         (ví dụ: công bố KQKD quý sau)
```
