# NHÀ MÁY TRÍ TUỆ TÀI CHÍNH — ARCHITECTURE v0.1

```text
HUMAN OWNER
    ▼
FINANCIAL GOVERNOR
    ▼
INTELLIGENCE ORCHESTRATOR
    ├──────────────────────────────┐
    ▼                              ▼
INVESTMENT INTELLIGENCE OS   FINANCIAL MEDIA OS
    └──────────────┬───────────────┘
                   ▼
          SHARED INTELLIGENCE CORE
     DATA/EVIDENCE · REASONING · LEARNING
                   ▼
             DURABLE MEMORY
                   ▼
              META-LEARNING ↺
```

Chuỗi trí tuệ: `DATA → EVIDENCE → UNDERSTANDING → HYPOTHESIS → CHALLENGE → TEST → RISK → DECISION → MEASURE → ATTRIBUTE → LEARN → IMPROVE HOW IT LEARNS`

## 1. Ba tầng
- **Universal Learning Core** — không chứa logic cổ phiếu: Observation, Hypothesis, Evidence, Experiment, Validation, Memory, Confidence, Learning, Meta-learning, Governance, Versioning. Tái dùng được cho YouTube, kinh doanh, ML.
- **Financial Intelligence Core** — Market Data, Fundamentals, Macro, Valuation, Quant, Portfolio, Risk, Regime, Backtesting, Attribution, Financial News.
- **Domain Systems** — Investment Intelligence OS; Financial Media OS.

## 2. Control Plane
Governor (`governance/GOVERNOR_POLICY.yaml`) + Orchestrator (`orchestrator/ORCHESTRATOR.md`). Nguyên tắc: ONE ORCHESTRATOR + SPECIALIST MODULES + STRICT CONTRACTS.

## 27. End-to-end Investment Workflow
```text
MARKET OBSERVATION → OPPORTUNITY → HYPOTHESIS → EVIDENCE COLLECTION → EXPERT ANALYSIS
→ ADVERSARIAL REVIEW → VALUATION / QUANT TEST → REGIME CHECK → RISK CHECK
→ BACKTEST / SIMULATION → PAPER TRADING → DECISION PACKAGE → HUMAN OWNER
→ SMALL CAPITAL → MONITOR → ATTRIBUTION → LEARNING → KNOWLEDGE → META-LEARNING ↺
```
