# AUTO MODE — kích hoạt bằng lệnh `AUTO HỌC HIỂU HÀNH ĐỘNG`

```text
READ PROJECT STATE → READ CAPABILITY STATE → IDENTIFY HIGHEST-LEVERAGE GAP → RESEARCH
→ CHALLENGE → SYNTHESIZE → SANDBOX TEST → VALIDATE → RECORD LEARNING → UPDATE STATE → SELECT NEXT GAP ↺
```

Chỉ dừng khi gặp cổng trong `governance/GATES.md`.
Mỗi vòng ghi một dòng vào `memory/episodic/` và cập nhật `state/CAPABILITY_STATE.yaml`.
Không được nâng capability lên `VALIDATED` chỉ vì đã đọc tài liệu — cần bằng chứng thực hành.
